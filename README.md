# Kovetz — сайт и руководство

Автономный статический сайт Kovetz на русском и английском. Готовые файлы в `site/` хранятся в Git. GitHub Pages публикует их при изменениях в `site/**` в ветке `main` и при ручном запуске workflow. В настройках Pages выберите GitHub Actions как способ публикации.

## Правки

- `content/landing.ru.json` и `content/landing.en.json` — тексты страниц, метаданные и общие подписи интерфейса. Поддерживайте одинаковый порядок разделов и вопросов на двух языках.
- `content/guide.ru.json` и `content/guide.en.json` — главы, шаги и подписи к снимкам. Снимки для руководства лежат в `assets/guide/<lang>/`, чистые снимки для лендинга — в `assets/screens/<lang>/`.
- `content/site.json` — название, версия приложения, базовый URL и внешние ссылки. При переезде сайта измените `baseUrl` и пересоберите сайт.
- `src/style.css` и `src/site.js` — общие стили и поведение. `design/` содержит визуальные референсы.

## Сборка и проверка

Установите Dart SDK и ImageMagick 7 (команда `magick`). Для установки зависимостей тестов один раз выполните `dart pub get`.

```sh
dart run tool/build_site.dart
dart test
```

Генератор пересоздаёт `site/` из исходников. Откройте `site/ru/index.html` или `site/en/index.html` в браузере для локального просмотра. После проверки сохраните изменения в исходниках и в `site/` в одном коммите.

## Выпуск приложения

При публикации релиза Kovetz обновите поле `version` в `content/site.json`, пересоберите сайт и запустите тесты. Проверьте, что ссылка `releases` открывает последний релиз, а новая версия отображается в разделе скачивания и в метаданных лендинга.
