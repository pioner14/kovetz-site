Вопросы и ответы

Заметки пропали после восстановления резервной копии. Что делать? expand_more

Восстановление в JW Library заменяет все данные устройства. Если у вас есть старые копии, соберите их Kovetz в одну и восстановите уже её.

Нужен ли интернет? expand_more

Нет. Он нужен только для скачивания программы и, по желанию, для проверки обновлений.

Безопасно ли это? expand_more

Исходные копии программа не меняет, результат сохраняется отдельным файлом. Перед восстановлением всё равно сделайте свежую копию устройства.

Что будет, если одна заметка изменена на двух устройствах? expand_more

Выберется более свежая версия, а вторая сохранится в отчёте.

Можно ли вернуть заметки в JW Library из PDF или Obsidian? expand_more

Нет: это для чтения и поиска. Вернуть заметки в JW Library можно только через общую резервную копию.

Это официальная программа JW Library? expand_more

Нет. Это независимый помощник; он не связан с JW Library и её разработчиками.
